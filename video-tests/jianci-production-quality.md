# 《剑刺》分镜、台词与成片检查规范

版本：1.0｜更新：2026-09-13｜作者：林爱丽

用途：以后每集制作前读取；换聊天时可直接上传本文件。以用户最新确认的剧本、角色图和成片为准，不能把旧版设定混入新版。本文件是制作规范，不代表任何未来成片已经通过检查。

## 1. 核心要求

先把剧情、台词、人物和分镜做清楚，再生成。交付前由制作方主动检查，不把用户当作第一轮质检人员。

- 风格：电影感二维日漫，冷灰蓝悬疑光影；不能为营造黑暗而让脸、证物看不清。
- 音频：清楚的中文对白、中英双语字幕、匹配剧情的 BGM。角色音色尽量一致。
- 连贯：上一镜的人物、位置、动作和道具状态，必须能接到下一镜。
- 节奏：没有新线索、情绪变化或诡异细节的照片停留段，约两秒即可，不用静止画面凑时长。展示、取出照片的动作另计，也要连起来检查总停留时间。
- 成本：优先沿用合格素材，避免重复付费。不能为了省生成费用而留下明显模糊、重复、换脸或动作错误。

## 2. 剧情与台词先核对

1. 明确本集解决什么、留下什么、如何承接上集和进入下集。
2. 真实案件先核实来源，区分史实、当事人的说法与虚构改编。未查证的内容不能写成事实。
3. 第一案与第二案分别列角色、受害者、嫌疑人、证物；没有剧情依据不得混用。
4. 分开记录“已证实”“角色推测”“待调查”。不能让人物提前知道尚未发现的线索。
5. 法医、调查、技术、人物关系可以多线推进，但每次切线要有问题或证据作为连接。
6. 每句台词注明说话人、对象、目的、起止时间，以及画内说话或画外音。人物名字自然出现在需要辨认身份的地方，不机械重复。
7. 台词按自然语速安排，给听懂和反应留时间；超时优先精简，不压速、不截尾字。
8. 吸血鬼反应由本案具体的人、物、声音或气味触发，逐步增加但保持克制。前世线索自然嵌入，不靠能力直接宣布凶手，不让所有人物沦为背景。

## 3. 角色与道具锁定表

每集先填写，使用明确的参考图或素材编号；“跟之前一样”不能代替可核对的参考。

| 对象 | 必须锁定的内容 | 本集允许的变化及原因 |
| --- | --- | --- |
| 每个角色 | 脸型、年龄感、发色、发型、扎发或散发、眼镜、衣服、音色 | 写明在哪一镜发生变化 |
| 特殊特征 | 助听器所在耳朵、伤疤、伤口、獠牙与眼睛状态 | 写清人物自身左右，区别画面左右 |
| 场景位置 | 谁在场、坐或站、朝向、彼此距离、进出方向 | 起身、坐下、走开需有可理解的衔接 |
| 照片 | 照片内人物、发型、服装、背景、边框、同一资产编号 | 只改变合理的拍摄角度，不另造一张脸 |
| 证物 | 形状、颜色、数量、所属案件、持有人、封装状态 | 转交、拆封、翻面需要动作或说明 |

第13集已确认的例子：第二案的母亲原本坐着、头发扎起，不能在提问镜头突然变成散发并与林浅并排。母亲拿出的女儿照片，必须与后续特写是同一张。

## 4. 分镜图制作要求

- 每镜只描述实际出场的人，不把全体角色表塞进每个生成提示，避免无关人物自动出现。
- 人物脸、发型、衣服和道具先在分镜图阶段核对；图不对，先修图再生成视频。
- 每镜标明开头和结尾状态，特别是手的位置、道具朝向、坐站状态和人物进出。
- 需要人物离开时，给出走出画面的动作或合理切镜；不能用身体渐隐代替离场。
- 同一空间建立位置关系；切反打时保持视线、方向和人物关系可理解。
- 分镜说明文字、角色表与最终画面分开。最终视频不得混入分屏分镜板、提示词或乱码。
- 为容易失败的动作预留一个合乎剧情的证物或手部插入镜头，不在出错后反复回放同一段人物动作。

## 5. 剪辑和修复原则

- 转场先解决叙事和动作衔接，不把加淡入淡出当作通用修复。人物叠影可能反而像变脸或消失。
- 可使用声音先于画面进入的剪法：例如照片上先听见剑刺开口，再切到他稳定的正面。出镜后的口型仍须对应声音。
- 没有必要的短促换角度应删去，避免一秒内接连改变构图。
- 同一张照片可做短而缓慢的推进，不用另生成的相似照片替代。
- 不回放已经出现的起身、等待或取物动作补时长；宁可合理缩短。
- 裁切前检查源素材清晰度、头脸边缘和景别。为遮住错误人物而突然大幅放大，是新的问题，不算修好。
- 删掉空白时间后，画面、音频和字幕同步移动，重新检查 BGM 接点和对白尾音。
- 从明确的最新版本修改，保留之前已通过的修复。多轮修改尽量汇总成剪辑清单并从原素材重建，减少反复压制造成的损失。

## 6. 交付前检查流程

### 第一遍：逐镜检查画面

- [ ] 同一个人的脸、年龄感、发型、眼镜、衣服一致。
- [ ] 没有串案人物、无关旁观者或重复角色。
- [ ] 坐站、视线、手势、走位、道具状态接得上。
- [ ] 没有透明、消失、重影、变脸、多手或穿帮。
- [ ] 照片与证物前后一致，所属案件正确。
- [ ] 脸和关键信息清楚，没有不必要的过度裁切。

### 第二遍：听声音并检查口型

- [ ] 画内人物明显说话时，有对应对白；有意静音须有叙事理由。
- [ ] 说话人与声音正确，没有一人动嘴、另一人发声。
- [ ] 台词完整，没有漏句、截断或重复。
- [ ] 中文字幕与实际对白一致；英文准确、可读，不遮住线索。
- [ ] BGM 不盖住对白，剪辑处没有突跳或爆音。

### 第三遍：连续播放检查节奏

- [ ] 从头到尾正常速度看一遍，不只看抽帧图。
- [ ] 每处转场前后一起看，动作、情绪和对白衔接自然。
- [ ] 没有明显重复镜头、长时间无信息停留或突兀换景别。
- [ ] 本案收尾与下案开场明确，观众不会误认嫌疑人。
- [ ] 结尾有明确的信息或情绪落点，不靠拖长静帧制造悬念。

### 每次修复之后

检查修改处前后至少各两秒，并核对相关角色或道具在本集的其他出场。全部修改合并后，再检查整集。不能只确认新文件导出成功就交付。

检查记录须写“通过／有问题／未核实”。如果只能查看抽帧或转录，应明确写出限制，不能声称已经完整听看验收。GitHub Actions 成功仅表示流程完成，不代表画面、声音和剧情合格。

## 7. 第13集问题备忘

以下时间来自当时被检查的不同版本；删减后时间会变化，不能直接套用到最新版。

| 当时的问题 | 后续制作应预防什么 |
| --- | --- |
| 35–36秒放大、模糊、叠影 | 不用突然大裁切掩盖背景人物错误 |
| 45–46秒第二案母亲出现在第一案证据复核 | 分案件锁角色，对白“锁定两人”尤其不能配错人物 |
| 1:04–1:11附近回放母亲等待镜头 | 修无声片段不能制造重复动作 |
| 林浅问话时母亲发型、位置变了 | 提问与回答镜头都需核对角色状态 |
| 1:15–1:17剑刺变透明、消失 | 检查整段运动，不只看首尾帧 |
| 1:19附近照片里女生改变 | 一张照片使用同一资产 |
| 照片切剑刺时连续换角度 | 让声音和稳定机位共同完成转场 |
| 照片无新增信息却停留过久 | 普通照片停留段约两秒，有明确叙事理由才延长 |

## 8. 成本、版本与交付

- 优先修剪辑、字幕和混音；合格片段不重复生成。
- 若现有素材无法可靠解决，先说明具体镜头、原因、最小重生成范围及费用估计，结合已有授权执行；不要把充值余额当成可随意花费的预算。
- 保存生成任务编号与原始结果；查询和恢复已有结果优先于再次提交付费任务。
- 保留原素材、角色参考、台词、字幕、剪辑清单和检查记录，便于下集复用。
- 交付明确的最新版，说明改了什么、检查范围、尚存限制和是否发生额外生成费用。
- 用户确认定稿后不擅自继续修改；本规范用于下一次制作，最新用户要求优先。
